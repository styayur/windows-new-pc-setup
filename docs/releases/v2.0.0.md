# SetupNewPC v2.0.0

将个人装机脚本重构为可配置、可预览、可重复执行的 Windows 11 装机工具。

## 下载与开始

下载本 Release 的 **SetupNewPC-v2.0.0.zip** 并完整解压，保留 `src/`、`config/` 和入口脚本。不要只下载单个 PS1。

在解压后的目录先预览：

```powershell
.\SetupNewPC_Optimized.ps1 -Profile Developer -WhatIf | ConvertTo-Json -Depth 8
```

审阅清单和软件许可后，在当前用户的管理员 PowerShell 中执行：

```powershell
.\SetupNewPC_Optimized.ps1 -Profile Developer -AcceptAgreements
```

要求 Windows 11、64 位 Windows PowerShell 5.1 或 PowerShell 7，以及 WinGet 1.8+。

## 主要变化

- 软件清单独立为 JSON，支持自定义清单、Profile、排除项、版本和安装范围校验。
- `-WhatIf` / `-Plan` 可在不提权、不联网、不创建状态的情况下预览。
- 修复 WinGet 失败输出被误判成功的问题；按退出码处理，安装后重新核验实际记录。
- 完善重试、安装超时停止、互斥锁、原子状态写入、机器与用户身份校验。
- 状态按配置隔离；中断或重启后执行相同命令，重新检查并补装缺少的软件。
- 逐项安装入口共享同一执行引擎，每个缺少的包仍需明确输入 Y。
- 增加双 PowerShell 回归测试、GitHub Actions、复用入口示例及虚拟机验收清单。

## 从 v1 升级：默认行为有变化

- WinUtil、WSL、Docker 和额外开发环境配置均改为显式启用；`Full` 不会自动启用这些功能。
- 不自动提权、重启或创建登录续跑任务；退出码 3010 时手动重启，再执行同一命令。
- 实际执行需传 `-AcceptAgreements`。个人偏好工具移入 Personal 分组。
- `-NoPause`、`-NoResume` 保留为兼容参数；`-AllowReboot` 明确报错。
- 新状态存放于 `%LOCALAPPDATA%\SetupNewPC\v2\<配置哈希>`，不导入 v1 状态。
- v1 的 DSC、PDF 和 TXT 资料移入 `legacy/`，仅供历史参考；不再维护脚本 TXT 镜像。
- 如果以前创建过 `SetupNewPC-Resume-After-Reboot` 任务，请按 README 的迁移说明检查并移除，避免旧脚本在登录时运行。

## 验证与边界

发布前在 Windows PowerShell 5.1 和 PowerShell 7 上各通过 25 项回归测试，覆盖配置、预览、参数转义、超时、失败重试、重启恢复、用户跳过、状态隔离及重复运行。测试使用模拟安装器，没有在开发机实际安装软件。

真实软件安装、BIOS 虚拟化、WSL 重启及 Docker 首次启动仍需按 `tests/VM-CHECKLIST.md` 在可恢复 Windows 11 虚拟机中验收。安装记录核验不等于每个应用的业务功能验收。

## 校验下载

使用同一 Release 的 `SHA256SUMS.txt` 对照 ZIP 的 SHA256：

```powershell
Get-FileHash .\SetupNewPC-v2.0.0.zip -Algorithm SHA256
```

完整用法、退出码和故障处理见包内 README。第三方软件遵循各自许可证。
