WINDOWS NEW PC SETUP · v2

一份清单，复用到下一台电脑。

先预览，再执行。软件按需安装，失败可重试，重启后重新核验。支持 Windows PowerShell 5.1 与 PowerShell 7。

查看仓库与完整说明 · 下载完整仓库 ZIP

1. 查看安装计划

解压整个仓库，保留 src 和 config 目录。在 PowerShell 中运行：

.\SetupNewPC_Optimized.ps1 -Profile Developer -WhatIf | ConvertTo-Json -Depth 8

2. 执行已审阅的清单

需要 Windows 11、64 位管理员 PowerShell 和 WinGet 1.8+。使用当前 Windows 用户的管理员终端：

.\SetupNewPC_Optimized.ps1 -Profile Developer -AcceptAgreements

默认不执行 WinUtil、不启用 WSL/Docker、不额外配置开发环境变量、不自动重启。

3. 按需启用功能

# WSL2 + Ubuntu + Docker Desktop
.\SetupNewPC_Optimized.ps1 -EnableDocker -AcceptAgreements

# 每个缺少的软件逐项确认
.\Install-Applications.WithConfirmation.ps1 -Profile Full -AcceptAgreements

# 使用自己的清单
.\SetupNewPC_Optimized.ps1 -ConfigPath .\config\my-packages.json -WhatIf

重启与恢复

返回码 3010 表示需要重启。保存工作、手动重启，再执行同一条命令。不会创建登录续跑任务；每次都会检查真实安装情况。

状态和日志位于 %LOCALAPPDATA%\SetupNewPC\v2\<配置哈希>。失败退出 1，参数或前置检查失败退出 2，用户跳过退出 3。
