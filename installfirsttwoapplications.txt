Windows 11 新机安装参考：Windows 基础 -> 重启 -> 开发环境

这是人工执行与脚本设计的同一份顺序参考。自动化版本请优先使用：

  SetupNewPC_Optimized.ps1

Profiles: Minimal / Developer / AI / Engineering / Full，可通过 -Profile 与 -IncludePersonal 选择。
如果 WSL/VMP 功能需要重启，脚本会保存状态并登记续跑任务。重启并登录后，
脚本自动从 Development 阶段继续；也可以手动再次运行同一脚本。


一、Windows 基础

0. 直接执行脚本（推荐）

   Set-Location "E:\Docs\configwenjian"
   Unblock-File .\SetupNewPC_Optimized.ps1
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
   .\SetupNewPC_Optimized.ps1 -Profile Developer

   主脚本会自动请求管理员权限；重启后会使用最高权限 Scheduled Task 续跑。
   默认下载 WinUtil 到本地并执行 Standard preset，不需要再手动传 EnableWinUtil。

   Clash Verge 是第一个软件安装项。

1. WinUtil 默认 Standard preset

   .\SetupNewPC_Optimized.ps1 -Profile Developer

   如需跳过：-SkipWinUtil

   如需固定校验：-WinUtilSha256 <64-hex-hash>

5. 启用 WSL/VMP 前置组件

   VirtualMachinePlatform 和 Microsoft-Windows-Subsystem-Linux 是 WSL2 与
   Docker Desktop WSL2 backend 的基础组件。启用后检查是否要求重启。


二、重启门

满足任一条件时应先重启，再进入开发环境阶段：

1. Windows Update 或组件安装要求重启。
2. VirtualMachinePlatform 状态不是 Enabled。
3. Microsoft-Windows-Subsystem-Linux 状态不是 Enabled。
4. wsl --status 提示需要更新或重启。
5. BIOS/UEFI 中刚启用 VT-x/AMD-V。

重启后检查:

   wsl --status
   wsl --version
   Get-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform
   Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux


三、开发环境

1. AI 工具

   ChatGPT 商店版:
   winget install 9PLM9XGG6VKS --source msstore -e

   OpenAI Codex:
   winget install --id OpenAI.Codex -e

2. WSL/Docker 深度检测与安装

   检测项:
   - CPU 固件虚拟化（HypervisorPresent、VirtualizationFirmwareEnabled）
   - VT-x/AMD-V 与 SLAT
   - VirtualMachinePlatform
   - Microsoft-Windows-Subsystem-Linux
   - WSL 状态、WSL 内核、默认版本
   - docker.exe、com.docker.service、docker-users

   初始化:

   wsl --update
   wsl --set-default-version 2
   wsl --install --distribution Ubuntu --no-launch

   全部前置条件通过后:

   winget install --id Docker.DockerDesktop -e

   如果当前用户刚加入 docker-users，请重新登录后再验证 Docker。

3. Python 分工

   系统 Python + uv：普通脚本、单文件工具、uv 项目开发。

   winget install --id Python.Python.3.13 -e
   winget install --id astral-sh.uv -e

   脚本设置 UV_PYTHON_PREFERENCE=system，让 uv 以系统 Python 为基础：

   uv init
   uv add <package>
   uv run <script-or-command>

   conda：科学计算、CUDA/ML、仿真和特定项目环境。

   winget install --id Anaconda.Anaconda3 -e
   conda init powershell
   conda config --set auto_activate_base false

   默认 python 保持为系统 Python；需要科学计算环境时显式执行：

   conda create -n science python=3.13
   conda activate science
   conda install <packages>
